Build a CLI-based profiler for Codex that helps developers understand what an agent is doing when a specific skill is invoked. The tool should connect to an existing Codex workflow and capture execution events in real time, including tool calls, commands, file operations, subagent creation, token usage, and execution time. When a developer invokes a skill such as `code-review` inside a project, the profiler should print a structured live trace of the resulting workflow to the terminal, showing how Codex executes the task and how resources are being used. The initial proof of concept will focus entirely on collecting, normalizing, and displaying these events in the CLI. Once the tracing pipeline works reliably, the same event data can later power an interactive visualization that displays the agent workflow as a live graph.
