# Domain Docs

Before working in this repository, read the root `CONTEXT.md` and relevant ADRs under `docs/adr/`.

This repository uses a single-context layout:

- `CONTEXT.md` defines the project's canonical domain vocabulary.
- `docs/adr/` records qualifying architectural decisions.

Use glossary terms consistently and avoid synonyms listed under `_Avoid_`. Surface any proposed change that conflicts with an existing ADR.
