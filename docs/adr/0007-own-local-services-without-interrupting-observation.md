# Own local services without interrupting observation

The `agent-tracer web` foreground command will start and own both the local Trace Explorer server and, by default, the shared Codex App Server so the primary workflow needs only one launcher plus the interactive Codex TUI. Browser disconnection will not stop collection, and normal shutdown requested during an active Skill Run will be deferred until observation and already-started Conformance evaluation settle; a second explicit interrupt may force termination after warning that the workflow can be interrupted. When `--server` connects to an externally owned App Server, the command will never stop that server. Keeping the services separate would make lifecycle ownership simpler, but would preserve the POC's three-terminal setup and make the browser experience needlessly operational.
